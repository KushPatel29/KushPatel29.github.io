# kushpatel29.github.io

My portfolio site — live at **[kushpatel29.github.io](https://kushpatel29.github.io/)**.

Hand-built static page: one HTML file, one stylesheet, one script. No
framework, no build step, no tracker. The dashboard screenshots are real
captures from my repos, and every number on the page (test counts, model
results, NRV figures) is CI-verified in the repo it comes from — the same
rule the portfolio itself is built on: no claim without a number, and no
number without a test.

- `index.html` — content
- `styles.css` — the "Meridian" palette from my Power BI dashboards, light + dark
- `main.js` — theme toggle, scroll reveals, stat count-up, terminal typing (all respect `prefers-reduced-motion`)
- `assets/` — compressed dashboard captures + OG banner
